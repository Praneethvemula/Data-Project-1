# 📊 Global Superstore Data Analysis Dashboard

> **An Excel-based data analysis and visualization project using the Global Superstore dataset.**

## 🔎 About the Project

This project focuses on analyzing the **Global Superstore dataset** and converting raw business data into meaningful visual insights using Microsoft Excel.

The workbook includes a dedicated dashboard along with supporting sheets for analyzing sales, returns, and regional information.

The main purpose of this project is to understand **sales performance, product categories, regions, and business trends** through data visualization.

---

## 🖥️ Dashboard

The project includes an Excel dashboard designed to provide a quick overview of the available sales data.

### Dashboard includes:

- 💰 Revenue analysis
- 📊 Category-wise analysis
- 🌍 Regional analysis
- 📦 Product/Sales analysis
- 🔄 Returns analysis
- 📈 Visual charts and summaries
